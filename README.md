# MJGR

Free Windows 11 media tools. Download installers, portable builds and source at
[mjgr.dev](https://mjgr.dev/).

| App | Purpose |
| --- | --- |
| Frame | Inspect video, seek by frame, adjust the picture, and save full-resolution frames. |
| Harbor | Archive channels with a reorderable queue, per-channel pause and a local library. |
| Thumbr | Browse video folders using cached contact sheets and scrub previews. |

Each release includes the exact version, download size and SHA-256 checksum.
Installers are per-user. Portable builds keep their profile beside the app.
The migration tools preview changes before copying an existing profile; media
libraries remain in their existing location.

Current Windows installers are unsigned. Signing status is stated with every
download. The applications bundle their required media tools.

Application source and dependency source inputs are available with the releases.
Their included license files describe the terms for each component.
